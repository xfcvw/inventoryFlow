# LinkedIn project description — English

**InventoryFlow — Full-Stack Inventory Management System**

InventoryFlow is a bilingual inventory and order management application built as a hands-on software development project.

The project evolved from a front-end prototype into a full-stack application backed by a Laravel REST API and PostgreSQL.

Implemented features include session-based authentication, authenticated REST endpoints, product CRUD, inventory movements, low-stock monitoring, order management, Portuguese/English localization, responsive UI, PostgreSQL persistence, Docker Compose, Nginx/PHP-FPM, automated tests and a GitHub Actions CI workflow.

**Technologies:** PHP, Laravel, PostgreSQL, JavaScript, HTML5, CSS3, Docker, Nginx, Git and GitHub Actions.
